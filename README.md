# lab-iot.github.io

📝 Catatan Pengembangan
Proyek ini dikembangkan sebagai alternatif open-source dan cross-platform untuk modul praktikum IoT di Universitas Muhammadiyah Surakarta (UMS). Dibangun dengan prinsip KISS (Keep It Simple, Stupid) dan DRY (Don't Repeat Yourself) untuk memudahkan pemeliharaan dan penambahan modul di masa depan.
